# 🏨 Hotel Reservation System
A Java-based Hotel Reservation System developed as part of the **CodeAlpha Java Programming Internship**. This project simulates a hotel booking system where users can explore room availability, make reservations, view booking details, and manage cancellations.

## 📌 Project Overview

The Hotel Reservation System is designed to simplify basic hotel booking operations through an interactive application. It demonstrates core Java programming concepts, object-oriented programming, and reservation management.

## ✨ Features

- **Room Availability:** View and search available hotel rooms.
- **Room Categories:** Organize rooms according to their categories.
- **Room Booking:** Create reservations by entering the required guest and booking details.
- **Reservation Management:** View booking information and manage existing reservations.
- **Booking Cancellation:** Cancel reservations when required.
- **Payment Simulation:** Demonstrate a basic payment process.
- **Cost Calculation:** Calculate the total booking amount based on applicable room rates and stay duration.
- **Data Storage:** Store reservation information using file handling, if implemented in the application.
- **Interactive Interface:** Navigate through the available options to perform booking operations.

## ⚙️ How to Run the Project

### Prerequisites

- Java Development Kit (JDK) installed on your system.
- A code editor or terminal, such as VS Code or IntelliJ IDEA.

### Step 1: Clone the Repository

```bash
git clone https://github.com/angelverma4296-maker/CodeAlpha_HotelReservationSystem.git
```

### Step 2: Open the Project

```bash
cd CodeAlpha_HotelReservationSystem
```

Open the project folder in your preferred Java IDE.

### Step 3: Compile the Code

If your Java source files are in the root directory:

```bash
javac *.java
```

If the project uses packages or a `src` directory, compile the files according to the project's folder structure.

### Step 4: Run the Application

Run the class containing the `main()` method. For example, if the main class is named `Main`:

```bash
java Main
```

**Note:** The compilation and execution commands may need adjustment depending on the actual source-file structure.

## 🔄 Application Workflow

1. Launch the application.
2. Select an option from the main menu.
3. View available rooms and their details.
4. Enter the required information to make a reservation.
5. Review booking details and payment information, where supported.
6. View or cancel an existing reservation.
7. Exit the application.
